Build 3D for the web without a hidden engine.

Verbis3D is an early-stage, independent 3D engine. Its math, scene graph, renderer, animation foundation and command safety layer are implemented directly, with no Three.js or other complete engine underneath.

Create and operate scenes in natural language.

One public API, explicit layers.

Code and natural language converge on the same validated engine operations. AI output is data—not executable JavaScript.

Engine-owned foundations

Column-major math, scene graph, cameras, geometry, materials, compound models and frame loop.

WebGL2 backend

Shader, buffer, VAO, render-state and resource lifecycle management.

Safe command path

Provider adapters emit schemas checked for command, target, range and permission.

Small enough to read. Complete enough to run.

The alpha API renders indexed geometry, editable car/person/face/tree hierarchies and supports offline Korean/English commands. 

const renderer = new WebGL2Renderer({ canvas });
const scene = new Scene();
const camera = new PerspectiveCamera(60, width / height, 0.1, 100);
const cube = new Mesh(
  new BoxGeometry(),
  new BasicMaterial({ color: [0.2, 0.7, 1, 1] })
);
scene.add(cube);
new Engine({ renderer, scene, camera }).start();

Current development stage

Version 0.1.0-alpha.1. Implemented features are separated from later work.

Implemented

Math, scene graph, camera, custom/primitive geometry, compound models, WebGL2 renderer, tests and Playground.

Validated path

Structured commands, dry-run, history, rule-based natural language and JSON scene round-trip.

Foundation only

Animation, textures, plugins and external AI adapters need production expansion.
