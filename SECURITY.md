# Security policy

The project is pre-release. Security fixes are supported on the latest `0.1.x` alpha branch only.

Report vulnerabilities privately through GitHub's **Report a vulnerability** feature. Do not open
a public issue with exploit details.

AI or JSON input that escapes structured validation, generated-code execution, credential
exposure, cross-origin provider leakage and resource-lifecycle denial of service are in scope.
Please include affected commit, reproduction, impact and suggested mitigation.
