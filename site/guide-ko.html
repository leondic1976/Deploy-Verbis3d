Verbis3D를 처음부터 사용해 보세요.

설치, WebGL2 장면, 객체 변형, 편집 가능한 자동차·얼굴, 안전한 자연어 명령을 실제 코드 순서대로 설명합니다.

현재 범위

Verbis3D는 TypeScript와 WebGL2로 직접 구현한 독립 3D 엔진입니다. 런타임 의존성에 완성형 3D 엔진이 없으며, 수학·장면 그래프·카메라·지오메트리·재질과 WebGL2 렌더 경로를 저장소에서 구현합니다.

자동차와 얼굴은 계층 모델링을 배우기 위한 절차적 예제입니다. glTF, 스키닝, 고밀도 얼굴 메시, PBR과 그림자는 아직 구현되지 않았습니다.

설치와 실행

git clone https://github.com/leondic1976/Deploy-Verbis3d.git
cd Deploy-Verbis3d
npm ci
npm run typecheck
npm run test
npm run site:dev

현재 버전은 0.2.0-alpha.1 소스 릴리스입니다. npm 게시 전이므로 다른 프로젝트에서 시험하려면 npm run build && npm pack으로 로컬 패키지를 만듭니다.

첫 장면

import {
  BasicMaterial, BoxGeometry, Engine, Mesh,
  PerspectiveCamera, Scene, WebGL2Renderer
} from "@verbis3d/core";

const canvas = document.querySelector("#stage");
if (!(canvas instanceof HTMLCanvasElement)) {
  throw new Error("canvas가 필요합니다.");
}

const renderer = new WebGL2Renderer({ canvas, maxDevicePixelRatio: 2 });
const scene = new Scene();
scene.background.set(0.025, 0.045, 0.065, 1);
const camera = new PerspectiveCamera(60, 1, 0.1, 100);
camera.position.set(0, 1.5, 5);
camera.lookAt({ x: 0, y: 0, z: 0 });

const cube = new Mesh(
  new BoxGeometry(),
  new BasicMaterial({ color: [0.2, 0.7, 1, 1] })
);
cube.name = "cube";
scene.add(cube);

const engine = new Engine({ renderer, scene, camera });
engine.onUpdate((dt) => cube.rotateY(dt));
engine.start();

canvas 크기가 바뀔 때 renderer.setSize(width, height, false)와 camera.resize(width, height)를 함께 호출하십시오. 화면을 제거할 때는 ResizeObserver를 끊고 engine.dispose()를 호출합니다.

객체 이동·회전·변형

object.position.set(2, 1, -3);
object.rotation.set(0, Math.PI / 4, 0);
object.scale.set(1, 2, 1);

object.translateX(1);
object.rotateY(Math.PI / 6);
object.lookAt({ x: 0, y: 0, z: 0 });

엔진 내부 각도는 라디안입니다. 부모 루트를 변형하면 자식이 함께 움직이고, 자식 transform을 변경하면 해당 부품만 부모 기준으로 바뀝니다. 장면 객체 이름은 자연어 대상이므로 고유하게 지정하는 것이 좋습니다.

자동차와 얼굴

const car = createProceduralCar({
  name: "study-car",
  bodyColor: [0.08, 0.56, 0.92, 1]
});
car.position.set(-2, -1.35, 0);
car.rotateY(Math.PI / 8);
scene.add(car);

const face = createProceduralFace({ name: "portrait" });
face.position.set(2, -1.35, 0);
scene.add(face);
face.getPart("mouth")?.scale.set(0.7, 0.14, 0.08);

const person = createProceduralPerson({
  name: "guide",
  shirtColor: [0.12, 0.58, 0.82, 1]
});
scene.add(person);
person.getPart("left-upper-arm")?.rotateZ(-0.4);

자동차 22개, 전신 사람 21개, 얼굴 18개, 나무 7개 파트를 기본 모델로 제공합니다. getPart()는 루트 이름과 무관한 안정적인 파트 ID를 사용하며, ModelFactory에 애플리케이션 전용 모델 템플릿을 추가할 수 있습니다.

자동차는 22개, 얼굴은 18개 선택 가능한 부품을 갖습니다. 루트는 전체 모델을 변형하고, {루트 이름}-{부품 역할} 이름으로 창문·바퀴·눈·입 등을 따로 조회할 수 있습니다. 일반 Object3D 계층이므로 JSON 저장과 복원도 같은 경로를 사용합니다.

자동차 편집얼굴 편집 모델 갤러리

임의 도형

내장 도형만 사용할 필요는 없습니다. Geometry에 position BufferAttribute와 index를 넣고 bounds를 계산하면 사용자 메시가 됩니다. 이 저수준 경계가 다양한 입체를 추가하는 기본 확장점입니다. 

const geometry = new Geometry()
  .setAttribute("position", new BufferAttribute(
    new Float32Array([0, 1, 0, -1, -1, 0, 1, -1, 0]), 3
  ))
  .setIndex([0, 1, 2]);
geometry.computeBoundingBox();
geometry.computeBoundingSphere();

여러 사진으로 3D 객체 만들기

Playground 상단의 Photos → 3D를 선택하고 같은 객체의 정면·측면 사진을 추가합니다. 각 사진의 촬영 방향을 지정한 후 오프라인, Ollama vision 또는 호환 Vision API를 선택할 수 있습니다.

  1. 객체 전체가 보이고 배경과 대비되는 사진을 2장 이상 준비합니다.
  2. Front와 Left side처럼 서로 수직인 방향을 지정합니다.
  3. 개인정보가 중요하면 사진을 전송하지 않는 Offline silhouette을 사용합니다.
  4. Create 3D object를 실행하고 신뢰도와 삼각형 수를 확인합니다.
  5. Edit in scene으로 이동해 위치·회전·재질을 계속 편집합니다.
현재 기준 구현은 실루엣 교집합으로 만드는 visual hull입니다. 사진 텍스처, 보이지 않는 오목한 부분, NeRF와 자동 리토폴로지는 아직 포함하지 않습니다. 전문 AI는 VisionAIProvider로 연결할 수 있습니다.

오프라인 자연어 명령

const controller = engine.useNaturalLanguage({
  provider: new RuleBasedProvider()
});

await controller.execute(
  "파란 자동차를 만들어 오른쪽으로 2 이동하고 30도 회전"
);

자연어는 EngineCommand[] 데이터로 바뀐 뒤 schema, 대상, 범위, 권한 검사를 통과해야 실행됩니다. eval이나 생성 JavaScript 실행은 없습니다. box, sphere, plane, car, person, face, tree 생성과 이동·회전·크기·색상·표시·복제 등을 지원합니다.

Ollama와 호환 API

const local = new OllamaProvider({
  model: "qwen3:8b",
  baseUrl: "http://127.0.0.1:11434"
});

const remote = new OpenAICompatibleProvider({
  baseUrl: "https://provider.example/v1",
  model: "command-model",
  apiKey
});

브라우저 직접 요청에는 endpoint의 CORS 허용이 필요합니다. 장기 API 키를 프런트엔드 번들에 넣지 말고 운영 환경에서는 서버 프록시를 사용하십시오. Playground 키 입력은 현재 탭 메모리에만 유지되고 storage와 장면 JSON에는 기록되지 않습니다.

Playground 권장 실습

  1. 객체 목록 또는 viewport에서 cube를 선택합니다.
  2. Inspector로 위치·회전·크기를 바꿉니다.
  3. 드래그 orbit, Shift 드래그 pan, 휠 zoom을 시험합니다.
  4. Builder에서 Car나 Face bust를 추가하고 루트를 변형합니다.
  5. 계층을 펼쳐 wheel, window, eye, mouth를 각각 선택합니다.
  6. 자연어 preview와 dry-run 결과를 확인한 뒤 실행합니다.
  7. Expert에서 장면 JSON을 내보내고 다시 불러옵니다.

문제 해결

  • 빈 화면이면 canvas 크기, 카메라 위치, near/far와 visible을 확인합니다.
  • 같은 이름이 있으면 자연어 명령이 AMBIGUOUS_TARGET으로 멈춥니다.
  • Ollama 실패 시 프로세스, endpoint, 모델 이름과 CORS를 확인합니다.
  • 복합 모델 전체가 안 보이면 루트를 선택하고 Frame selected를 누릅니다.
  • 고밀도 외부 모델 로드는 아직 glTF 범위가 구현되지 않았습니다.
