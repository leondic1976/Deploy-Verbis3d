Roadmap

From readable alpha to durable engine.

0.1 alpha · current

Math core, scene graph, cameras, basic primitives/material, WebGL2 indexed rendering, animation/command foundations, natural-language scene creation, progressive Scene Lab, 16 verified learning sources, viewport picking and camera navigation, provider selection, JSON scene round-trip and documentation site.

0.2 · robustness

GPU cache invalidation, triangle-precise picking and transform gizmos, reversible core commands, AnimationClip-backed command motion, provider proxy guidance, texture sampling, render sorting and performance budgets.

0.3 · asset pipeline

glTF subset, async dependency graphs, worker decoding and explicit asset ownership.

Later

WebGPU backend, skeletal animation, editor tooling and provider-specific AI integrations. These are planned, not implemented.
