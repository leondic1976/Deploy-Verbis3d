Documentation / 0.1 alpha

Build your first Verbis3D scene.

The current package is an alpha source release. The examples below match the checked-in public exports.

Installation

npm install @verbis3d/core
Repository status: the package API is versioned as 0.1.0-alpha.1; publishing to npm is not part of this release workflow.

First scene

import {
  Engine, Scene, PerspectiveCamera, WebGL2Renderer,
  Mesh, BoxGeometry, BasicMaterial
} from "@verbis3d/core";

const renderer = new WebGL2Renderer({ canvas });
const scene = new Scene();
const camera = new PerspectiveCamera(60, canvas.clientWidth / canvas.clientHeight, 0.1, 100);
camera.position.set(0, 1.5, 5);
const cube = new Mesh(new BoxGeometry(), new BasicMaterial({ color: [0.2, 0.7, 1, 1] }));
scene.add(cube);
const engine = new Engine({ renderer, scene, camera });
engine.onUpdate((dt) => cube.rotateY(dt));
engine.start();

Math

Vectors, quaternions and matrices are mutable to support output reuse. Matrices are column-major and angles are radians internally. A zero vector normalizes to zero; a singular matrix inversion throws RangeError.

Scene graph

Object3D rejects cycles, supports visible traversal, and propagates local/world dirty state. Direct vector mutations through public methods invalidate cached transforms.

Camera

Perspective and orthographic cameras maintain projection, view, view-projection and frustum state. Public perspective field-of-view values are degrees.

Renderer

The backend creates WebGL2 buffers, index buffers, VAOs and shader programs, then emits indexed or non-indexed calls. Context creation failures provide a user-facing compatibility message.

Geometry & materials

Box, plane and UV sphere primitives provide positions, normals, UVs, indices and bounds. BasicMaterial uses GLSL ES 3.00 and a solid RGBA uniform.

Animation

Scalar, Vector3 and Quaternion tracks support linear or spherical interpolation. Actions expose play, pause, stop, loop, speed and seek controls. Skeletal animation is not implemented.

Commands & AI

const controller = engine.useNaturalLanguage({
  provider: new RuleBasedProvider()
});
await controller.execute("큐브를 오른쪽으로 2 이동");

Provider output always passes the runtime validator and command bus. Deletion is permission-gated; ambiguous names stop execution; dry-run is supported. 

await controller.execute(
  "빨간 구를 만들어 오른쪽으로 2 이동하고 천천히 회전시켜"
);

The offline grammar can create box, sphere and plane objects, then chain movement, rotation, motion, scale, color, visibility, duplicate or delete operations.

Progressive Playground

Scene Lab exposes Beginner, Builder, Advanced and Expert levels without replacing the active scene. It combines canvas picking, orbit/pan/zoom, multi-object hierarchy editing, selection-aware natural language, optional Ollama or compatible API settings, material state, motion, undo/redo, structured command dry-runs and scene JSON.

Plugins & assets

Plugins have install/uninstall lifecycle isolation. JSON scenes serialize supported primitives and colors. Texture loading uses createImageBitmap; full glTF support is future work.
