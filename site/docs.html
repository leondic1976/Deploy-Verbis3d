Documentation / 0.3 alpha

Build your first Verbis3D scene.

The current package is an alpha source release. The examples below match the checked-in public exports.

Installation

npm install @verbis3d/core
Repository status: the package API is versioned as 0.3.0-alpha.1; publishing to npm is not part of this release workflow.

First scene

import {
  Engine, Scene, PerspectiveCamera, WebGL2Renderer,
  Mesh, BoxGeometry, BasicMaterial
} from "@verbis3d/core";

const renderer = new WebGL2Renderer({ canvas });
const scene = new Scene();
const camera = new PerspectiveCamera(60, canvas.clientWidth / canvas.clientHeight, 0.1, 100);
camera.position.set(0, 1.5, 5);
const cube = new Mesh(new BoxGeometry(), new BasicMaterial({ color: [0.2, 0.7, 1, 1] }));
scene.add(cube);
const engine = new Engine({ renderer, scene, camera });
engine.onUpdate((dt) => cube.rotateY(dt));
engine.start();

Math

Vectors, quaternions and matrices are mutable to support output reuse. Matrices are column-major and angles are radians internally. A zero vector normalizes to zero; a singular matrix inversion throws RangeError.

Scene graph

Object3D rejects cycles, supports visible traversal, and propagates local/world dirty state. Direct vector mutations through public methods invalidate cached transforms.

Camera

Perspective and orthographic cameras maintain projection, view, view-projection and frustum state. Public perspective field-of-view values are degrees.

Renderer

The backend creates WebGL2 buffers, index buffers, VAOs and shader programs, then emits indexed or non-indexed calls. Context creation failures provide a user-facing compatibility message.

Geometry & materials

Box, plane and UV sphere primitives provide positions, normals, UVs, indices and bounds. BasicMaterial uses a solid RGBA uniform. VertexColorMaterial renders normalized per-vertex RGBA projected from reconstruction photos.

Procedural object models

ModelFactory is an application-owned template catalog. The built-in catalog creates editable car, full-body person, face and tree hierarchies; custom templates use the same validated primitive builder. 

const models = createBuiltinModelFactory();
const person = models.create("person", {
  name: "guide",
  colors: { shirt: [0.12, 0.58, 0.82, 1] }
});
person.getPart("left-upper-arm")?.rotateZ(-0.4);
scene.add(person);

Stable part IDs, semantic color roles, independent cloning, command-bus creation and JSON restoration are covered by the core API. These alpha assets are stylized primitives, not production character meshes.

Create 3D from multiple photos

PhotoReconstructionPipeline validates 2–12 decoded views, delegates object recognition and segmentation to a replaceable VisionAIProvider. Ordered VisionAnalysisEnhancer stages can add depth and calibrated camera poses, while an independent VisionMeshGenerator can build the final mesh. 

const controller = new AbortController();
const pipeline = new PhotoReconstructionPipeline(
  new RuleBasedVisionProvider()
);
const result = await pipeline.reconstruct(
  [frontPhoto, leftPhoto],
  {
    name: "captured-object",
    resolution: 24,
    enhancers: [new SilhouetteDepthEnhancer()],
    projectColors: true,
    signal: controller.signal
  }
);
scene.add(result.mesh);

The engine fallback is depth/pose-aware, cancellable and yields during voxel work. Optional photo projection produces vertex colors. The bundled silhouette depth remains a local shape approximation, not metric depth, and the result is not a photorealistic NeRF or production retopology.

Animation

Scalar, Vector3 and Quaternion tracks support linear or spherical interpolation. Actions expose play, pause, stop, loop, speed and seek controls. Skeletal animation is not implemented.

Commands & AI

const controller = engine.useNaturalLanguage({
  provider: new RuleBasedProvider()
});
await controller.execute("큐브를 오른쪽으로 2 이동");

Provider output always passes the runtime validator and command bus. Deletion is permission-gated; ambiguous names stop execution; dry-run is supported. 

await controller.execute(
  "빨간 구를 만들어 오른쪽으로 2 이동하고 천천히 회전시켜"
);

The offline grammar can create box, sphere, plane, car, person, face and tree objects, then chain movement, rotation, motion, scale, color, visibility, duplicate or delete operations.

Progressive Playground

Scene Lab exposes Beginner, Builder, Advanced and Expert levels without replacing the active scene. It combines canvas picking, orbit/pan/zoom, multi-object hierarchy editing, selection-aware natural language, optional Ollama or compatible API settings, material state, a guided Photos → 3D workflow, motion, undo/redo, structured command dry-runs and scene JSON.

Plugins & assets

Plugins have install/uninstall lifecycle isolation. JSON scenes serialize supported primitives, validated custom buffer geometry and colors. Texture loading uses createImageBitmap; full glTF support is future work.
