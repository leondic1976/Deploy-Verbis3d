Roadmap

From readable alpha to durable engine.

0.3 alpha · current

Math core, scene graph, cameras, basic primitives/material, WebGL2 indexed rendering, animation/command foundations, natural-language scene creation, progressive Scene Lab, 21 verified learning sources, editable car/person/face/tree hierarchies, provider-neutral multi-AI reconstruction stages, calibrated pose/depth carving, cancellable visual hulls, photo vertex colors, viewport picking, camera navigation, JSON scene round-trip and English/Korean documentation.

0.4 · robustness and texture quality

GPU cache invalidation, triangle-precise picking and transform gizmos, reversible core commands, AnimationClip-backed command motion, provider proxy guidance, texture sampling, render sorting, performance budgets, bundled camera-pose models, UV texture atlases and reconstructed-mesh smoothing.

0.5 · asset pipeline

glTF subset, async dependency graphs, worker decoding and explicit asset ownership.

Later

WebGPU backend, skeletal animation, editor tooling and provider-specific AI integrations. These are planned, not implemented.
